# tpmp-lab2-task3



## Overview

Данный проект демонстрирует работу со структурами данных на языке C с использованием модели КИС-2 (клиент-сервер-интерфейс). 

Проект включает в себя:

- Определение структур в заголовочных файлах (интерфейс)

- Реализацию функций работы со структурами (сервер)

- Клиентский код для демонстрации функционала

## Model KIS-2 (Клиент-Интерфейс-Сервер)

- **Интерфейс** (`student.h`) - объявление структур и прототипов функций

- **Сервер** (`student_operations.c`) - реализация функций

- **Клиент** (`main.c`) - использование функций
